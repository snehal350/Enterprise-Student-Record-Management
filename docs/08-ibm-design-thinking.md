# IBM Design Thinking Report

## 1. Focus on User Outcomes
The platform should help users complete academic tasks accurately and efficiently rather than merely providing additional features.

## 2. Restless Reinvention
The proposed solution should improve continuously using stakeholder feedback, prototype testing, and changing institutional requirements.

## 3. Diverse Empowered Teams
Students, faculty, administrators, examination staff, and technical team members should contribute different perspectives during product planning.

## Application to the Project
- Identify meaningful user outcomes.
- Review assumptions using feedback.
- Encourage collaboration among stakeholder groups.
- Improve proposed features through iterative testing.

## Conclusion
These principles guide the development of a useful and adaptable academic management platform.
