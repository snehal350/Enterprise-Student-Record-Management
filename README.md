# Enterprise Student Record and Academic Management Platform

## Unit 1 Mini Project
**Design Thinking and Product Planning**

## Project Overview
The Enterprise Student Record and Academic Management Platform aims to organize student records and academic information within a higher education institution.

The proposed platform focuses on student registration, course information, attendance management, examination results, and academic report generation.

## Problem Statement
Manual academic record management can lead to duplicated records, data-entry errors, delays in retrieving information, and difficulties generating academic reports.

## Project Objectives
- Understand the academic management process.
- Identify stakeholders and their needs.
- Apply the five stages of Design Thinking.
- Define functional and non-functional requirements.
- Develop the product vision and minimum viable product (MVP).
- Prepare the initial system architecture and product roadmap.
- Maintain project documentation using Git and GitHub.

## Project Scope
This unit focuses on business understanding, product discovery, requirements, design thinking, and planning. Application implementation can be planned for subsequent development units.

## Repository Structure
- `docs/` — Project requirements and discovery documentation
- `diagrams/` — System architecture diagrams
- `planning/` — Milestones and project planning
- `PROJECT_CHARTER.md` — Project objectives, scope, risks, and milestones
